# Project documentation

Keep one canonical copy of each document in this folder. General product and engineering references live at this level; `advisor-references/` contains unique advisor methodology, requirements, meeting notes, and original source material.

Generated HTML versions should be regenerated from their Markdown source instead of edited separately. Public examples must use synthetic names, contact details, and financial values. Do not commit client exports or identifiable client records.

The application implementation is maintained in `src/`; calculation code and advisor references should be reviewed together when methodology changes.
